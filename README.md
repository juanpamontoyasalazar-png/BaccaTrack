# BaccaTrack 3.1

Versión profesional con evaluación estadística walk-forward.

## Incluye
- Identidad visual BaccaTrack y logo oficial.
- Registro Banca / Jugador / Empate.
- Deshacer última mano varias veces.
- Filtro de prudencia: score mínimo + diferencia mínima entre alternativas.
- Etiqueta de confianza del modelo.
- Backtest walk-forward usando solo información disponible antes de cada mano.
- Métricas de precisión y cobertura del modelo.
- Panel de administración y licencias.

> El sistema es una herramienta de análisis experimental. Las métricas históricas no garantizan el resultado de una mano futura.

## Ejecutar en Windows

Desde la carpeta que contiene `package.json`:

```powershell
npm.cmd install
node server.js
```

Abrir `http://localhost:3000`.
